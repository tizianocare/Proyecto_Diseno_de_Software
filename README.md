# Trabajo EGI: Observer - SubastaYa

Implementacion en Java del patron de diseno Observer aplicada a una subasta en vivo.

Repositorio: https://github.com/tizianocare/mi-proyecto-diseno

Autores:

- Lisandro Feudale
- Valentino Pepa
- Tiziano Caré

## Requisitos

- JDK 21 o posterior
- Windows, Linux o macOS

## Compilar y ejecutar

Desde la raiz del proyecto:

```bash
javac -encoding UTF-8 -d out src/subasta/*.java
java -cp out subasta.Main
```

En Windows tambien puede ejecutarse:

```bat
run.bat
```

## Contenido

- `src/subasta/`: clases de la solucion.
- `diagrama-clases.puml`: diagrama UML en PlantUML.
- `Documento-EGI.md`: documento exigido con las cuatro secciones.
- `PRESENTACION-EGI.md`: guia breve para la presentacion oral.
- `salida-utf8.txt`: evidencia de una ejecucion exitosa.
